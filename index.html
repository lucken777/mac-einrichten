Mac einrichten

MacBook Pro 2016: erst macOS aktualisieren, dann beide Content-Maschinen in deinem Mac-Benutzer. Safari ist dein privater Browser, Chrome der für Physiopoly. Hak jeden Schritt ab, sobald er erledigt ist. Der Haken bleibt in diesem Browser gespeichert.

A

Vor dem Update

Das Update ersetzt nur das System. Alle Benutzer und ihre Dateien bleiben erhalten, auch die deiner Freundin.

  1. A1Freundinals Nächstes

    Das Update betrifft auch ihren Benutzer. Frag, ob sie sehr alte Programme nutzt (etwa vor 2015, z. B. altes Office oder Adobe). Die starten danach nicht mehr, ihre Dateien bleiben aber.

  2. A2Freundinals Nächstes

    Entweder gibt sie ihr Passwort beim Update ein, oder sie macht deinen Benutzer zum Admin:

    • Apple-Menü → Systemeinstellungen → Benutzer & Gruppen
    • unten links auf das Schloss klicken, ihr Passwort eingeben
    • deinen Benutzer wählen, Häkchen bei „Der Benutzer darf diesen Computer verwalten“

    Als Admin brauchst du später nur noch dein eigenes Passwort, z. B. auch beim Installieren von Chrome (E1).

  3. A3Macals Nächstes

    Time Machine auf eine externe Festplatte: Festplatte anstecken, dann Systemeinstellungen → Time Machine → Backup-Volume auswählen. Das sichert alle Benutzer, also nur mit ihrem Einverständnis.

  4. A4Macals Nächstes

    Apple-Menü → Über diesen Mac → Reiter Festplatten. Der freie Platz zählt für den ganzen Mac.

  5. A5Macals Nächstes

    Das Update dauert 1–2 Stunden. Den Deckel offen lassen.

B

macOS Monterey installieren

Monterey (macOS 12) ist die neueste Version, die Apple für ein MacBook Pro 2016 anbietet. Kostenlos.

  1. B1Browserals Nächstes

    In Safari öffnen: apps.apple.com/de/app/macos-monterey. Der App Store geht auf, dort auf Laden klicken (etwa 12 GB).

    Geht der Link nicht: support.apple.com/de-de/102662 öffnen und bei „macOS Monterey“ auf den App-Store-Link klicken.

  2. B2Freundinals Nächstes

    Bist du nach A2 selbst Admin, reicht dein eigenes Passwort.

  3. B3Macals Nächstes

    Das Fenster „macOS Monterey installieren“ öffnet sich von selbst. Dann Fortfahren → der Lizenz zustimmen → Festplatte „Macintosh HD“ wählen → Installieren.

    Nicht das Festplattendienstprogramm öffnen und nichts löschen.

  4. B4Macals Nächstes

    Er startet mehrmals neu, zwischendurch ist der Bildschirm schwarz mit Apfel und Balken. Das ist normal, nicht zuklappen und nicht ausschalten.

  5. B5Macals Nächstes

    Fragen zu Apple-ID, Siri usw. kannst du mit „Später“ oder „Überspringen“ beantworten.

C

Nach dem Update prüfen

  1. C1Terminalals Nächstes

    Im Terminal einfügen, Enter. Dort muss Python 3.15.2 stehen.

    python3 --version
  2. C2Terminalals Nächstes

    Hier sollte eine Versionsnummer erscheinen.

    git --version

    Kommt stattdessen invalid active developer path: das hier einfügen, im Fenster auf Installieren klicken und warten. Danach nochmal prüfen.

    xcode-select --install
  3. C3Browserals Nächstes

    Safari ist nach dem Update aktuell genug und bleibt dein privater Browser. Dort meldest du dich auf claude.ai mit deinem privaten Konto an. Diese Seite findest du dort unter deinen Artifacts wieder.

D

Private Maschine einrichten

Privat, also in Safari mit deinen privaten Konten. Ordner: ~/content-maschine-diy, Adresse localhost:8757.

  1. D1Terminalals Nächstes

    Schon erledigt am 04.11. (Resolving deltas … done). Der Ordner bleibt beim Update erhalten.

  2. D2Browserals Nächstes

    kie.ai mit deinem privaten Konto öffnen → links API Key → einen neuen Key erzeugen → kopieren.

    Den alten Key noch nicht löschen, das kommt erst in D13.

  3. D3Terminalals Nächstes

    Einfügen, Enter. Zuerst baut es die Python-Umgebung und lädt Pakete. Das dauert 2–3 Minuten. Gelbe Warnungen von „pip“ kannst du ignorieren.

    bash ~/content-maschine-diy/einrichten.command
  4. D4Terminalals Nächstes

    Bei Einfügen (Cmd+V, bleibt unsichtbar) drückst du Cmd+V und dann Enter. Man sieht dabei nichts, das ist richtig. Danach muss ✓ KIE_KEY gespeichert (32 Zeichen) erscheinen.

  5. D5Terminalals Nächstes

    Es kommen etwa zehn Fragen wie Optional: IMGBB_KEY … eintragen? [j/N]. Bei jeder einfach Enter drücken.

  6. D6Terminalals Nächstes

    Meist steht dort nur kein *bilder*.zip gefunden, das ist in Ordnung. Fragt es nach physio-bilder.zip, tippst du n und Enter. Die gehören zur Firma.

  7. D7Terminalals Nächstes

    Bei Claude Code … jetzt versuchen? [j/N] tippst du j und Enter. Es gibt zwei mögliche Ergebnisse:

    • → Claude Code läuft auf diesem Rechner nicht: Die Texte laufen über KIE. Einfach weitermachen.
    • ✓ Claude Code läuft hier: Nach dem Einrichten musst du dich einmal anmelden. Der Befehl unten öffnet den Browser, dort meldest du dich mit dem privaten Claude-Konto an. Danach im Terminal /exit tippen.
    ~/.local/bin/claude
  8. D8Terminalals Nächstes

    Es laufen 17 Zeilen mit ✓ durch, dann steht dort == Fertig. Drück eine beliebige Taste. Steht irgendwo ein ✗: Screenshot an Claude.

  9. D9Terminalals Nächstes

    Der Browser öffnet http://localhost:8757/sprueche-pro.html. Der Report ist leer, solange keine Excel-Listen drin sind. Das ist richtig so. Lass das Terminalfenster offen, sonst ist die Maschine aus.

    bash ~/content-maschine-diy/start.command
  10. D10Macals Nächstes

    Im Finder Cmd+Shift+H → Ordner content-maschine-diy → Rechtsklick auf start.command → Alias erzeugen. Das Alias in „Start privat“ umbenennen und ins Dock ziehen, rechts neben den Papierkorb. Danach reicht ein Klick. Kommt „kann nicht geöffnet werden“: Rechtsklick → Öffnen.

  11. D11Macals Nächstes

    Die Exporte legst du nach ~/content-maschine-diy/Seiten/<Gruppe>/<Seite>.xlsx, z. B. Seiten/1 Mondbaby/Mondbaby.xlsx. Gruppen-Exporte kommen nach Seiten/6 Gruppe/. Danach das Maschinen-Fenster schließen und neu starten.

  12. D12PCals Nächstes

    Am PC diese Datei mit dem Editor öffnen:

    C:\Users\LUCK9R\Desktop\AI JACK\2-ECOMMERCE\content-maschine-diy\config.json

    Bei "KIE_KEY" den alten Wert durch den neuen ersetzen und speichern. Hast du auch bei imgbb einen neuen Key, genauso bei "IMGBB_KEY". Den Key bitte nicht in den Chat schreiben.

  13. D13Browserals Nächstes

    Erst jetzt auf kie.ai den alten Key löschen. Dann schreib Claude im Chat „neuer Key ist drin“. Ich starte die PC-Maschine neu und prüfe den Key ohne Kosten. Mondbaby Studio, Video-Studio und Nachgedanken lesen ihn aus derselben Datei.

E

Physiopoly-Maschine einrichten

Im selben Mac-Benutzer, aber in Chrome. Dort meldest du nur Firmen-Konten an, Safari bleibt privat. Ordner: ~/physiopoly-content-maschine, Adresse localhost:8790. Beide Maschinen können gleichzeitig laufen, jede in ihrem eigenen Terminalfenster.

  1. E1Browserals Nächstes

    In Safari google.com/chrome öffnen → Chrome herunterladen → die Datei googlechrome.dmg öffnen → das Chrome-Symbol auf Programme ziehen.

    Fragt der Mac nach einem Admin-Passwort und du hast keins: Chrome stattdessen in deinen Benutzerordner ziehen. Dafür im Finder Cmd+Shift+H, dort einen Ordner „Programme“ anlegen. Bietet Google für Monterey keine Version mehr an, nimm Firefox als Firmen-Browser.

  2. E2Browserals Nächstes

    In Chrome meldest du dich an bei: claude.ai (Firmen-Abo), kie.ai (Firma), console.apify.com und firecrawl.dev. Die Frage nach Synchronisierung mit einem Google-Konto kannst du mit „Nein“ beantworten.

    Faustregel: In Chrome kein privates Konto, in Safari kein Firmen-Konto.

  3. E3Safarials Nächstes

    Der Mac merkt sich nur eine GitHub-Anmeldung. Darum bekommt dein vorhandener Token „Mac privat“ das zweite Repo einfach dazu:

    • in Safari öffnen: github.com/settings/personal-access-tokens
    • den Token „Mac privat“ anklicken → Edit
    • bei Repository access zusätzlich physiopoly-content-maschine auswählen. content-maschine-diy bleibt dabei ausgewählt.
    • Contents bleibt auf Read-only → unten Update
  4. E4Terminalals Nächstes

    Einfügen, Enter. Normalerweise fragt git diesmal nicht nach dem Passwort, weil der Mac den Token schon kennt. Am Ende steht Resolving deltas … done.

    git clone https://github.com/lucken777/physiopoly-content-maschine.git ~/physiopoly-content-maschine

    Kommt Repository not found: E3 wurde noch nicht gespeichert. Fragt es doch nach einem Passwort: Bei Username lucken777 eingeben. Für das Password auf der Token-Seite Regenerate token klicken, den neuen Token kopieren und einfügen. Der Mac merkt sich dann den neuen.

  5. E5PC / USBals Nächstes

    Am PC liegt physio-bilder.zip (224 MB, 1.093 gesicherte Instagram- und TikTok-Bilder) hier:

    C:\Users\LUCK9R\Desktop\AI JACK\2-ECOMMERCE\physiopoly-content-maschine\_fuer-den-mac

    Auf dem Mac legst du sie direkt in den Ordner physiopoly-content-maschine: im Finder Cmd+Shift+H und dann diesen Ordner öffnen. Nicht auf den Schreibtisch und nicht in Downloads, sonst fragt auch die private Maschine danach.

  6. E6Chromeals Nächstes

    Kopier jeden erst, wenn das Skript danach fragt:

    • KIE: kie.ai → API Key
    • Apify: console.apify.com → Settings → API & Integrations
    • Firecrawl: firecrawl.dev → Dashboard → API Keys

    Fehlt dir ein Key noch, drück im Skript Enter und hol ihn später nach. Dafür startest du das Einrichten einfach nochmal.

  7. E7Terminalals Nächstes
    bash ~/physiopoly-content-maschine/einrichten.command
    • Nacheinander KIE_KEY, APIFY_TOKEN und FIRECRAWL_API_KEY einfügen: jeweils Cmd+V, dann Enter
    • optionale Fragen [j/N]: Enter
    • ✓ … Listen nach Seiten/ kopiert: das sind deine Physio-Listen vom 21.07.
    • physio-bilder.zip übernehmen? [J/n]: Enter, das heißt ja
    • Claude Code … jetzt versuchen? [j/N]: n. In diesem Mac-Benutzer gehört Claude Code zu deinem privaten Konto.
    • Tests mit ✓, dann == Fertig, beliebige Taste
  8. E8Terminalals Nächstes

    Sonst würde die Firmen-Maschine ihre Texte über dein privates Claude-Abo schreiben. Einfügen, Enter. Danach muss ok erscheinen. Stand in D7 „läuft nicht“, hak diesen Schritt einfach ab.

    python3 -c "import json,os; p=os.path.expanduser('~/physiopoly-content-maschine/config.json'); d=json.load(open(p)); d['TEXT_KI']='kie'; json.dump(d, open(p,'w'), indent=2); print('ok')"
  9. E9Terminalals Nächstes
    bash ~/physiopoly-content-maschine/start.command

    Es geht dein Standard-Browser auf. Die Maschine selbst hängt an keinem Konto, du kannst sie auch in Chrome öffnen. Dafür diese Adresse in Chrome aufrufen und als Lesezeichen speichern:

    http://localhost:8790/sprueche-pro.html

    Für das Dock: Rechtsklick auf start.command → Alias erzeugen → das Alias in „Start Physiopoly“ umbenennen → ins Dock ziehen. So sind die beiden Start-Symbole nicht zu verwechseln.

  10. E10Browserals Nächstes

    Einen Physio-Beitrag auswählen, Style 2.2 anklicken. Oben muss 💰 Spar-Bild · 4 Credits stehen. Dann ⚡ Generieren. Das Ergebnis erscheint unter 🖼️ Ergebnisse.

  11. E11Chromeals Nächstes
    • In Chrome claude.ai/code öffnen, angemeldet mit dem Firmen-Abo
    • GitHub verbinden. Bei der Installation der Claude-App Only select repositories wählen und beide Repos anhaken: physiopoly-content-maschine und content-maschine-diy. Beide Claude-Konten nutzen dieselbe App auf deinem GitHub-Konto.
    • In Chrome wählst du danach immer nur physiopoly-content-maschine.

Später: Updates und Änderungen

  1. F1Terminalals Nächstes

    Das Maschinen-Fenster schließen, den Befehl ausführen und dann wieder starten. Deine Listen, Bilder, Ergebnisse und Keys bleiben dabei unberührt.

    bash ~/content-maschine-diy/aktualisieren.command
    bash ~/physiopoly-content-maschine/aktualisieren.command
  2. F2Browserals Nächstes
    • claude.ai/code öffnen: Safari mit deinem privaten Konto und Repo content-maschine-diy, Chrome mit dem Firmen-Abo und Repo physiopoly-content-maschine
    • Beim ersten Mal in Safari ebenfalls GitHub verbinden. Die Claude-App ist seit E11 schon für beide Repos freigegeben.
    • Repo auswählen und den Wunsch reinschreiben. Claude ändert, testet und macht einen Pull Request
    • Auf github.com → Pull requests → Merge pull request → Confirm merge
    • Auf dem Mac aktualisieren, wie in F1
  3. F3PCals Nächstes

    Wurde unterwegs etwas geändert, sagst du Claude am PC „hol die neue Version“. Ändert Claude etwas am PC, sagst du „hochladen“, dann holt es der Mac mit F1.

Wenn etwas hakt

„Python 3.9 oder neuer fehlt“
Ein neues Terminalfenster öffnen (Cmd+N) und den Befehl nochmal starten. Kommt es wieder, das Ergebnis von C1 an Claude schicken.
„invalid active developer path“
Mit xcode-select --install die Entwicklertools neu installieren, siehe C2.
„kann nicht geöffnet werden“ bei einer .command-Datei
Rechtsklick auf die Datei → Öffnen → Öffnen. Oder den Befehl mit bash … ins Terminal kopieren.
„Repository not found“ beim git clone
Der Token kennt das Repo noch nicht. Den Token wie in E3 bearbeiten und beide Repos auswählen.
Die Maschine startet nicht, oder der Browser zeigt nichts
Läuft schon ein altes Fenster der Maschine? Das schließen und neu starten.
